# IsleWhispers 原生播放器设计

## 目标

将 `/Users/db/Downloads/Mobile-App` 中的 iOS/iPadOS 设计交付实现为现有 `IsleWhispers` UIKit 工程中的原生应用。应用适配 iPhone 与 iPad，使用包内 15 种环境音频，当前声音循环播放，不提供播放进度界面。

## 技术选择

- 保留 UIKit 生命周期和现有 Xcode 工程，不迁移 SwiftUI。
- 使用纯代码视图层和 Auto Layout；约束通过 SnapKit 表达。
- 使用 CocoaPods 管理 SnapKit；按用户确认保持最小依赖，不引入 IQKeyboardManager 或 Alamofire。
- 最低支持 iOS 15.0，并保持 iPhone/iPad Universal 设备族设置。
- 音频基于 `AVAudioPlayer`；启用 `.playback` 音频会话和后台音频模式。
- 使用 `MPRemoteCommandCenter` 与 `MPNowPlayingInfoCenter` 提供锁屏播放、暂停、上一种和下一种控制。

## 产品结构

### 声库与主播放器

主界面展示 15 种环境声和当前播放状态。

- iPhone 使用纵向滚动布局：标题、当前声音卡片、播放控制和三列声库。
- iPad 常规宽度使用双栏布局：左侧单列声库，右侧大尺寸播放器。
- iPad 分屏或窄窗口降级为单栏滚动布局，避免固定设备判断。
- 点击声音时更新选中状态并进入该声音的独立播放页；若此前正在播放，则新声音立即继续循环播放。

### 独立播放页

独立播放页使用所选声音对应的图片作为沉浸式背景。

- iPhone 为纵向布局：顶部返回和睡眠定时入口，中部标题与播放控制，下方睡眠定时及声音切换。
- iPad 常规宽度使用播放器主区域与右侧控制栏；窄窗口改为单栏。
- 不显示进度条、已播放时间或总时长，也不维护面向 UI 的播放进度状态。
- 播放控制只包含上一种、播放/暂停、下一种。

## 播放行为

- 15 个 CAF 文件与对应背景图复制进应用资源目录，并以稳定的 `Sound` 模型关联名称、副标题、音频文件和图片。
- 当前音频通过 `AVAudioPlayer.numberOfLoops = -1` 无限循环；音频自然结束时不切换下一种。
- 上一种、下一种和直接选择声音均按 15 项循环取值。
- 切换声音时保留播放意图：播放中切换会立即播放新声音，暂停中切换保持暂停。
- 保存最后选择的声音索引，下次启动恢复选择，但不自动开始播放。
- 播放状态、当前声音和睡眠定时由单一 `AudioPlayerService` 管理，两个页面观察同一状态，避免各自创建播放器。

## 睡眠定时

- 提供不限、15、30、60 分钟四个选项。
- 新选择会替换旧定时；选择“不限”会取消定时。
- 定时到期暂停播放器并清除定时状态，不切换声音。
- 定时使用基于截止日期的状态判断，在应用进入前台时重新校正，避免普通计时器因后台挂起造成明显偏差。

## 视觉系统与适配

- 从设计交付映射白色背景、浅灰表面、深色前景、淡蓝强调色、圆角、阴影和 SF 字体层级。
- 独立播放页根据当前声音切换背景图，并叠加深色渐变与模糊效果保证文字可读性。
- 所有主要控件最小点击区域为 44 点，支持 VoiceOver 标签和 Dynamic Type。
- 布局依赖 safe area、trait collection 和容器宽度；不硬编码具体 iPhone/iPad 型号。
- iPhone 与 iPad 均支持现有工程声明的方向；iPad 横竖屏和 Stage Manager 窗口变化会实时重排。

## 代码边界

- `Models/Sound.swift`：声音元数据。
- `Services/AudioPlayerService.swift`：播放、循环、切换、音频会话、远程控制和睡眠定时。
- `UI/Theme.swift`：设计颜色、字号、间距和圆角。
- `Views/`：播放器卡片、播放控制、声音单元格、定时选择器等可复用视图。
- `ViewControllers/LibraryViewController.swift`：主声库与响应式主播放器。
- `ViewControllers/PlayerViewController.swift`：沉浸式独立播放页。
- `SceneDelegate.swift`：创建根导航控制器并注入共享播放器服务。

不会引入除 SnapKit 之外的第三方库，也不会增加网络、账号、下载、混音或播放进度功能。

## 错误与中断处理

- 资源缺失或解码失败时保持应用可操作，显示简短错误状态，播放按钮允许重试。
- 电话、Siri 等系统中断结束后仅在系统允许且中断前正在播放时恢复。
- 耳机拔出等 route change 触发暂停，避免意外从扬声器继续播放。
- 后台音频会话配置失败时不崩溃，并在界面反映未能播放。

## 验证

- 为声音索引循环、切换时播放意图、睡眠定时状态和最后选择持久化编写单元测试。
- 使用 `pod install` 生成 workspace 后，通过 `IsleWhispers/IsleWhispers.xcworkspace` 编译。
- 至少验证一个小屏 iPhone、一个标准 iPhone、iPad 竖屏、iPad 横屏和窄分屏尺寸。
- 手工验证播放/暂停、无限循环、上一种/下一种、直接选声、睡眠定时、后台继续播放和锁屏控制。
- 检查界面中不存在进度条、时长或已播放时间。
