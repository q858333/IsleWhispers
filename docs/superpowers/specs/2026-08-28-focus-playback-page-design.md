# IsleWhispers 专注播放页设计

日期：2026-08-28

## 目标

在现有 iPhone 竖屏双 Tab 应用上增加一个独立的全屏播放页：用户点击首页中央播放按钮后，当前声音立即开始播放并打开该页面。页面提供当前声音背景、倒计时、播放/暂停、关闭和声音切换能力，并在有限倒计时结束时自动暂停且发送本地通知。

本设计以用户提供的 `IMG_4592.PNG` 作为布局与氛围参考，不复制其中的品牌、文案或无关功能。

此前设计中的“界面不显示进度或时长”继续适用于首页和声音列表；本次经用户明确确认的倒计时仅出现在新的专注播放页，不显示音频播放进度、已播放时长或音频总时长。

## 产品范围

### 包含

- 首页中央按钮启动当前声音并全屏打开专注播放页。
- 专注播放页显示当前声音的全屏背景、名称、倒计时和播放控制。
- 倒计时支持不限时、15 分钟、30 分钟和 60 分钟。
- 播放与倒计时同步暂停、同步恢复。
- 右上角打开半屏声音列表，选中后切换并自动播放。
- 有限倒计时结束后自动暂停、停留在播放页、显示 `00:00` 和关闭按钮。
- 有限倒计时创建本地结束通知；修改、暂停、关闭时同步更新或取消。
- 继续支持现有后台音频、锁屏控制、无限循环、最近播放和第二个 Tab。

### 不包含

- iPad、横屏、Split View 或 Stage Manager 支持。
- 音频进度条、音频已播放时长或音频总时长。
- 保存专注播放页的会话状态供下次进入恢复。
- 新的倒计时时长、自定义输入或云端通知。
- 混音、多声音叠加或新的音频资源。

## 页面进入与退出

### 进入

首页中央按钮不再直接切换播放/暂停，而是执行统一入口：

1. 读取 `AudioPlayerService` 当前选择的声音。
2. 如果当前未播放，则开始播放；如果已经播放，不重启音频。
3. 以 `.fullScreen` 模态方式展示 `FocusPlaybackViewController`，覆盖 Tab Bar。
4. 使用当前睡眠定时选项初始化显示；默认或已清除状态显示 `∞`。

首页右上角静音按钮继续只负责静音/恢复，不改变播放状态，也不打开播放页。

### 退出

关闭按钮只在暂停或倒计时结束后显示。点击后：

1. 立即暂停音频并释放播放会话。
2. 取消未送达的结束通知。
3. 将倒计时清为不限时。
4. 关闭全屏播放页。
5. 保留当前选择的声音和最近播放记录，但不保存本次剩余时间、暂停状态或页面状态。

再次从首页进入时从 `∞` 开始，不恢复上次专注会话。

## 页面布局与视觉

`FocusPlaybackViewController` 使用当前声音图片作为全屏背景：

- 图片采用 `scaleAspectFill` 等比铺满，超出部分裁切。
- 使用低强度模糊和暗色遮罩保证白色文字可读，模糊程度不高于当前首页。
- 左上角在安全区内显示当前声音名称，使用动态字体。
- 右上角为半透明胶囊形“切换声音”按钮，可使用波形或调节图标，并提供明确的 VoiceOver 标签。
- 左下角显示大号倒计时；不限时显示 `∞`，有限时间统一显示 `MM:SS`，例如 `15:00`、`00:09`、`00:00`。
- 右下角显示圆形主控制按钮：播放时为暂停，暂停或结束后为继续播放。
- 暂停或结束后，主控制按钮旁边出现独立的圆形关闭按钮；播放时关闭按钮隐藏。

布局使用安全区和 Auto Layout，在 iPhone 小屏、刘海屏和灵动岛机型上保持可访问。辅助大字体下允许标题换行、操作区扩大或纵向调整，不允许按钮互相覆盖或超出安全区。App 仍仅支持竖屏。

## 播放与倒计时状态

### 单一状态源

声音选择、实际播放状态和睡眠倒计时继续由共享 `AudioPlayerService` 管理。专注播放页只负责呈现和发送用户操作，不创建第二个音频播放器，也不维护一份会与服务冲突的当前声音。

`SleepTimerState` 扩展为能够表达以下状态：

- 不限时：没有截止时间，也不安排通知。
- 运行中：保存有限选项和绝对截止时间。
- 已暂停：保存精确的剩余秒数，不保留活动截止时间。
- 已结束：剩余时间为 0，供页面稳定显示 `00:00`，直到用户关闭或重新选择时间。

现有 `SleepTimerOption` 的不限时、15、30、60 分钟选项保持不变。服务增加精确暂停和恢复能力，避免把不足整分钟的剩余时间重新取整。

### 操作规则

- 选择有限时间：替换旧倒计时和旧通知；若声音正在播放，则从当前时刻开始新的完整倒计时，若声音已暂停，则先保存完整剩余时间并等待继续播放后再生成截止时间。
- 选择不限时：清除倒计时并取消通知，音频播放状态不变。
- 点击暂停：暂停声音，记录精确剩余时间，停止内部计时并取消通知。
- 点击继续：继续当前声音；若存在暂停的有限倒计时，则从剩余时间生成新截止时间并重新安排通知。
- 从系统控制中心执行暂停/继续时，沿用相同的倒计时暂停/恢复规则，页面通过播放器通知同步按钮与时间。
- 切换声音：不重置倒计时预算；新声音立即播放。如果倒计时原本暂停，则选择后按用户要求自动播放，并从保存的剩余时间恢复倒计时。
- 用户主动选择新的时间后，即使旧状态为 `00:00`，也可开始新的倒计时。

页面使用一秒 UI 刷新计时器显示剩余时间，但真实剩余时间始终由绝对截止时间计算，避免锁屏、后台或主线程延迟造成逐秒累积误差。

### 倒计时结束

有限倒计时到达截止时间后：

1. `AudioPlayerService` 自动暂停当前声音。
2. 倒计时进入“已结束”状态，不立即重置为不限时。
3. 播放页显示 `00:00`、继续按钮和关闭按钮，并保持在当前页面。
4. 对应的本地通知由系统送达。

若用户在 `00:00` 状态点击继续，则声音恢复播放，但倒计时保持结束状态且不重复通知；用户需重新选择一个时长或不限时。这样可避免结束后立即形成新的隐式倒计时。

## 声音切换

右上角按钮以 `.pageSheet` 打开复用的 `SoundLibraryViewController`：

- iOS 15 使用半屏 detent；无法使用指定 detent 时退化为系统 page sheet。
- 列表保持与第二个 Tab 相同的渐变背景、分组和卡片样式。
- Sheet 提供清晰的标题和关闭入口。
- 点击声音后调用应用现有的统一选择与播放流程，写入最近播放记录，刷新首页和第二个 Tab 的选中状态。
- 选择成功后自动关闭 Sheet，并更新播放页标题与背景。
- 不切换根 Tab，不关闭专注播放页，不重置剩余倒计时。

为避免两个列表控制器之间共享可变视图状态，Sheet 创建新的 `SoundLibraryViewController` 实例，但仍注入同一播放器选择回调和当前声音标识。

## 本地通知

增加轻量、可注入测试的 `PlaybackEndNotificationScheduling` 协议及基于 `UNUserNotificationCenter` 的实现，通知使用固定标识，确保同一时间最多存在一条播放结束通知。

### 权限与调度

- 用户第一次选择有限倒计时时请求通知权限；若此时播放已暂停，只请求权限而不安排通知，恢复播放后再按新截止时间安排。
- 获得权限后，在当前截止时间安排标题为“播放已结束”的本地通知，并使用默认提示音。
- 修改有限时间时先取消旧通知，再按新截止时间安排。
- 暂停、选择不限时或关闭页面时取消未送达通知。
- 恢复有限倒计时时按新的截止时间重新安排。
- 权限被拒绝或调度失败时，不弹出额外错误页，不影响本地倒计时和自动暂停。

`AppDelegate` 设置 `UNUserNotificationCenterDelegate`。App 位于前台时也允许显示横幅和声音；后台或锁屏时由系统按授权状态展示。

本地通知只负责告知用户，不能作为执行自动暂停的代码回调。应用在可执行状态时由服务内部计时器暂停音频；重新进入前台时通过绝对截止时间校正并立即处理已过期倒计时。iOS 可能在应用挂起时延后业务代码执行，因此实机验收需单独记录后台截止时音频停止的系统限制与实际结果，不把通知送达误当成音频已停止的证据。

## 状态同步与生命周期

- 播放页订阅 `.audioPlayerStateDidChange`，同步声音、播放按钮、关闭按钮和倒计时。
- 远程控制、音频中断或路由变化导致播放状态改变时，页面立即更新，不自行强制重新播放。
- 声音变更时更新背景和标题；使用短交叉淡化，不引入首页轮播动画。
- 一秒 UI 刷新计时器仅在页面可见且有限倒计时运行时存在。
- 页面关闭或销毁时移除通知观察者并停止 UI 计时器。
- App 回到前台时调用现有协调入口校正截止时间；过期状态只处理一次。

## 错误与降级

- 音频加载或播放失败：页面保留当前背景与控件，显示现有简短错误和重试入口；不自动切换声音。
- 背景图片缺失：使用现有暖色渐变占位。
- 通知权限拒绝或调度失败：倒计时照常运行，仅不发送通知。
- Sheet 被用户下拉关闭：保持当前声音和倒计时不变。
- 快速重复点击播放、暂停或选择时间：所有操作保持幂等，最多保留一个内部计时器和一个待发送通知。

## 可访问性

- 倒计时以完整中文读法作为 accessibility value，例如“剩余十五分钟”或“倒计时已结束”。
- 主控制按钮明确朗读“暂停播放”或“继续播放”。
- 关闭按钮朗读“关闭播放页”，并只在可见时参与可访问性导航。
- 声音切换按钮朗读“切换声音，当前雨声”等上下文信息。
- 遵守动态字体、增强对比度和减弱动态效果；减弱动态效果时背景变化仅使用短淡化。

## 测试与验收

### 状态与服务测试

- 有限倒计时按绝对时间计算剩余秒数。
- 暂停保存精确剩余时间，恢复生成正确的新截止时间。
- 不限时、修改时间、暂停和关闭会取消通知。
- 恢复或重新选择有限时间只安排一条新通知。
- 倒计时结束只触发一次自动暂停，并稳定保留结束状态。
- 通知权限拒绝或调度错误不改变播放和倒计时结果。
- 远程暂停/继续与页面操作遵守同一倒计时规则。

### 页面与集成测试

- 首页中央按钮在未播放时启动音频并全屏呈现播放页。
- 已播放时点击首页中央按钮只呈现页面，不重启音频。
- `∞`、`MM:SS` 和 `00:00` 显示正确。
- 播放时隐藏关闭按钮；暂停和结束时显示关闭按钮。
- 关闭后音频暂停、倒计时恢复不限时、通知取消、声音选择保留。
- Sheet 选择声音后自动播放、记录最近播放、更新背景并自动关闭，倒计时保持或按暂停状态恢复。
- 小屏 iPhone 和辅助字号下，标题、倒计时、切换、播放和关闭按钮均在安全区内可访问。
- 首页和声音列表仍不显示播放进度、已播放时长或总时长。

### 工程验证

- 相关 focused XCTest 先失败后通过。
- 默认 XCTest 全量通过。
- generic iOS Simulator 构建通过。
- 构建产物继续仅支持 iPhone 和 Portrait，最低系统版本保持 iOS 15。
- 实机验证通知授权允许/拒绝、前台通知、后台通知、锁屏控制、耳机拔出和来电中断，并分别记录通知送达与音频停止结果。

## 完成标准

- 首页中央按钮可靠进入独立全屏播放页，并保证当前声音正在播放。
- 播放页视觉结构与参考图一致，保持 IsleWhispers 当前暖色主题和低模糊背景。
- 播放、暂停、关闭、声音切换和倒计时形成单一一致状态流。
- 有限倒计时结束后自动暂停、显示 `00:00` 并发送本地通知；权限拒绝不影响核心行为。
- 关闭页面后不保存本次专注会话，且不破坏当前声音选择、最近播放、后台音频和现有两个 Tab。
- 自动化验证通过，必须依赖真机或系统调度的边界被明确记录。
