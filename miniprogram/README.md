# IsleWhispers 微信小程序

## 本地校验

```bash
npm run verify
```

该命令校验 16 个 CC0 音频的许可证清单、文件散列和全部纯逻辑测试。

## 微信开发者工具

导入本目录；`project.config.json` 中的 AppID 保持为空，或由运营者在本机填写自己的 AppID。不要在仓库中写入 AppSecret、管理员微信号或其他凭据。

首次打开进入本地服务条款和隐私保护指引；确认后可使用首页、声音库和设置页。音频为本地 MP3，不需要音频 CDN 或 H5 业务域名。

## 提审前

逐项执行 `REVIEW_CHECKLIST.md`。微信后台的用户隐私保护指引必须与小程序本地隐私文案一致；如未来新增任何隐私接口，必须先更新指引并取得用户同意。
